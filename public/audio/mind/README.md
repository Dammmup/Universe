# Музыка нейронов разума

Клик по нейрону на уровне «Разум» включает трек этого состояния: эмбиент слоя
приседает, трек поднимается кроссфейдом и идёт по кругу, пока выбран нейрон.
Уход со слоя или другой нейрон его снимают.

Записи сюда не положены намеренно: это коммерческие релизы, права на них у
правообладателей. Движок к этому готов — **чего нет, то просто молчит**:
загрузка падает, путь запоминается как пустой, слой звучит процедурным
эмбиентом, как раньше. Ничего не ломается и в консоль не сыплется.

## Как добавить свои файлы

Положить рядом с этим файлом `<id>.mp3` — имя берётся из `MIND_TRACKS` в
[`src/data/mind.js`](../../../src/data/mind.js). Подойдёт любой формат, который
играет браузер (mp3, ogg, m4a, wav); если меняешь расширение — поправь `file` в
`MIND_TRACKS`.
